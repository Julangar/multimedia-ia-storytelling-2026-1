# Cómo seguir avanzando con el Entregable E

## Objetivo del Entregable E
Realizar una evaluación más contundente de las herramientas comparando:
1. condición base,
2. prompt refinado,
3. uso de referencias visuales (si la herramienta lo permite).

## Recomendación experimental mínima
Trabajar con **3 escenas de H3**:
- S01 (presentación)
- S04 (estrés por viento/movimiento)
- S07 (atmósfera interior / detalle)

## Condiciones a comparar
### ChatGPT
- Base (la prueba actual)
- Prompt refinado (repitiendo anclas resumidas en cada escena)
- Opcional: con imagen de referencia de personajes si la plataforma lo permite dentro del flujo

### Leonardo
- Base
- Prompt refinado
- Con Image Guidance premium:
  - Character Reference
  - Style Reference
  - Content Reference (solo si realmente aporta)

### Ideogram
- Base
- Prompt refinado
- Verificar si alguna guía por imagen está disponible para el plan usado

## Qué medir en E
- alineación al prompt,
- consistencia de personaje,
- consistencia de estilo,
- calidad visual,
- utilidad para storyboard,
- control experimental.

## Criterio fuerte de comparación
El foco de E ya no debe ser “qué imagen se ve más bonita”, sino:
- cuál herramienta responde mejor al refinamiento,
- cuál mejora más con referencias,
- y cuál ofrece mejor balance entre consistencia, esfuerzo y costo.
