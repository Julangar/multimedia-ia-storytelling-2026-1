# CEUR paper skeleton

This folder contains a first CEURART-oriented skeleton for a potential ICAI/WAAI workshop paper.

Files:
- `paper_case_study_outline.tex`
- `paper_refs.bib`
- `ceurart.cls`
- `elsarticle-num-names.bst`

The skeleton is not a final paper. It is intended to align the remaining project work with a 12-15 page CEUR-style workshop submission.
