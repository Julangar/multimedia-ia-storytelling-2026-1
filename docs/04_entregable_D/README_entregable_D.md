## Propósito
Este entregable demuestra el flujo completo:
**narrativa → escenas → prompts → imágenes → storyboard**

Se tomó como base la historia **H3 – El Mapa del Viento** y se construyó un storyboard completo de 8 escenas usando **Leonardo Phoenix 1.0** como herramienta principal.
