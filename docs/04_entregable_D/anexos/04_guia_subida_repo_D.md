# Guía para subir Entregable D al repo

## 1. Archivos principales
Sube estos archivos a:

```text
docs/04_entregable_D/
├── Entregable_D_GI-II_2026-1_Julian_Garcia.pdf
├── Entregable_D_GI-II_2026-1_Julian_Garcia.docx
├── Storyboard_H3_El_Mapa_del_Viento.pdf
├── README_entregable_D.md
└── anexos/
```

## 2. Anexos
Dentro de `docs/04_entregable_D/anexos/` sube:
- `01_seleccion_variantes_H3.csv`
- `02_bitacora_resumida_D.csv`
- `03_prompt_finales_H3_v3.md`
- `04_guia_subida_repo_D.md`
- `05_correo_envio_entregable_D.md`
- `06_resumen_avance_estado_proyecto_D.md`
- `07_plan_entregable_E.md`
- `08_observaciones_consistencia_y_mejora.md`
- carpeta `figuras/` (si decides conservar tableros visuales de apoyo)
