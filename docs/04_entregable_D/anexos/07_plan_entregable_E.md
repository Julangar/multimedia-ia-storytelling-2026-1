# Plan operativo — Entregable E

## Objetivo
Realizar una **evaluación comparativa más contundente** entre herramientas de generación de imágenes, comparando:
1. modo base / libre,
2. prompts refinados,
3. uso de referencias visuales o guías de personaje/estilo cuando la herramienta lo permita.

## Enfoque recomendado
Comparar al menos estas tres herramientas:
- ChatGPT Images (capacidades incluidas en Plus)
- Leonardo (modo free / pipeline actual y, si decides pagar, modo con Image Guidance)
- Ideogram (modo free)

## Diseño experimental sugerido
Trabajar con un set pequeño y controlado:
- 2 escenas por historia, o
- 1 historia con 3 escenas críticas

Condiciones:
- **Condición A:** prompt base
- **Condición B:** prompt refinado
- **Condición C:** prompt + referencia visual (si aplica)

## Qué medir
- Alineación al prompt
- Consistencia de personaje
- Consistencia de estilo
- Calidad visual
- Utilidad para storyboard
- Control práctico / reproducibilidad

## Preguntas clave de E
- ¿Cuánto mejora realmente la consistencia cuando se usa referencia visual?
- ¿Qué tan distinta es la calidad entre modo free y modo guiado/premium?
- ¿Qué herramienta ofrece el mejor equilibrio entre calidad, control y costo/limitación?

## Salidas esperadas
- Tabla comparativa por herramienta y condición
- Bitácora de pruebas refinadas
- Discusión sobre free vs guided
- Recomendación metodológica final para el proyecto
