# Observaciones de consistencia y mejora — Entregable D

## Hallazgo principal
El storyboard logró una secuencia visual completa de 8 escenas para **H3 — El Mapa del Viento**, pero la consistencia de rostro y estilo no fue totalmente estable entre escenas.

## Problemas detectados
- Variación en facciones y edad aparente de Nico y Sara.
- Cambios leves entre acabado painterly e ilustración más renderizada.
- Algunas escenas fortalecen el mapa como objeto visual pero debilitan el reconocimiento de los personajes.

## Interpretación
Con la configuración usada en Leonardo Phoenix 1.0 y sin ayudas premium de referencia, se logró un nivel funcional de coherencia para storyboard académico, pero no una consistencia de personaje “cerrada” al nivel de producción.

## Decisión metodológica
Este resultado es suficiente para **Entregable D** porque demuestra el flujo completo guion → prompts → imágenes → storyboard.  
Sin embargo, también justifica que el **Entregable E** explore funciones avanzadas de referencia de imagen y ajustes más controlados, para comparar:
- modo base / libre
- modo guiado por referencias
- mejora por refinamiento iterativo de prompt
