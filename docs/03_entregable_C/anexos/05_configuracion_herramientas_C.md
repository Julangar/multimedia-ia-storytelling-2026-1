# Configuracion de herramientas usadas — Entregable C

## ChatGPT
- Modelo: Ultimo modelo disponible en ChatGPT para generacion de imagen.
- Relacion de aspecto observada: las escenas de 16:9 y las que estaban pensadas para 4:3 se mantuvieron visualmente en composicion horizontal, sin ajuste manual adicional durante este corte.
- Variaciones generadas: 1 imagen final por escena.
- Costo: sin costo extra adicional sobre el plan utilizado.

## Leonardo AI
- Modelo: Phoenix 1.0
- Prompt Enhance: Off
- Style: Dynamic
- Contrast: Medium
- Generation Mode: Fast
- Image Dimensions:
  - 16:9 -> Medium 1376 x 768
  - 4:3 -> Custom Medium 1184 x 896
- Number of images: 4 por escena
- Negative Prompt: On
- Use Fixed Seed: On (observacion del autor: no funciono de forma adecuada)
- Plan free: 150 tokens, con reinicio aproximado cada 7 horas
- Costo observado: 24 tokens por escena (4 imagenes)

## Ideogram
- Modelo: Auto (3.0)
- Count: 4 imagenes por escena
- Aspect Ratio: 16:9 y 4:3
- Style: Auto
- Color: Auto
- Magic Prompt: Off
- Plan free: sin seed ni negative prompt disponible
- Creditos: 20 creditos, con reinicio aproximado cada 4 dias
- Costo observado: 2 creditos por escena (4 imagenes)
