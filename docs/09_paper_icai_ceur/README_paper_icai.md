# ICAI/CEUR paper material - AI-assisted storyboarding case study

## Tentative title
A Case Study on AI-Assisted Storyboarding: Evaluating Prompting and Visual Reference Strategies for Narrative and Character Consistency

## Preliminary abstract
This paper presents an applied case study on AI-assisted storyboarding using generative image tools. The study follows a controlled workflow from narrative design to scene specification, prompt construction, image generation, and storyboard assembly. Three short stories were designed as test cases, and a focused adventure story was selected for deeper evaluation. ChatGPT Images, Leonardo Phoenix, and Ideogram were compared under different conditions, including baseline prompting, refined prompts, and visual-reference-assisted generation. Results suggest that visual references improved character and style consistency more effectively than text-only prompt refinement in the evaluated conditions. The study discusses tool limitations, free-plan constraints, prompt drift, object inconsistency, and the practical requirements for reproducible academic evaluation of AI-generated storyboards.
