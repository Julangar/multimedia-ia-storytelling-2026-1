# Actualización sugerida para README.md

## Cierre GI-II 2026-1

Este repositorio documenta el proyecto **Storytelling y Storyboarding asistidos con IA**, desarrollado para Grupo de Investigación II (GI-II 2026-1) en el Grupo Multimedia Interactiva y Animación Digital de la Universidad Distrital Francisco José de Caldas.

### Productos finales
- `docs/06_entregable_F/`: informe comparativo final.
- `docs/07_entregable_final/`: documento final consolidado.
- `docs/08_poster/`: póster de investigación.
- `docs/09_paper_icai_ceur/`: material base para paper/ponencia.
- `outputs/evidencia_final/`: selección de evidencia visual final.

### Hallazgo principal
El uso de referencias visuales mejoró la consistencia de personajes y estilo más que el refinamiento textual del prompt por sí solo, dentro del caso de estudio H3 - El Mapa del Viento.
